## Installation

<p align="center">
1. Download the latest release.
<p align="center">
2. Extract the `Ships (P) Pirate` folder.
<p align="center">
3. Move it to your Starsector `mods` folder.
<p align="center">
4. Launch Starsector.
<p align="center">
5. Enable **Ships (P) Pirate** in the mod manager.
</p>

## Requirements

- Starsector **0.98a-RC8**
- No additional dependencies

## Installation

1. Download the latest release.
2. Extract the `Ships (P) Pirate` folder.
3. Move it to your Starsector `mods` folder.
4. Launch Starsector.
5. Enable **Ships (P) Pirate** in the mod manager.
